# LD14 Studio V0.2

## 文件

- `ld14_viewer_v0_2.py`：二维扫描上位机。
- `LD14_ESP32_Bridge.ino`：ESP32 USB/WiFi 双链路桥，沿用V0.1。
- `requirements.txt`：Python依赖。

## V0.2更新

- 移植官方SDK的LD14测距中心修正参数和公式。
- 保持LD14左手坐标：0度正前方，角度顺时针增加。
- 加入官方SDK包角跨度有效性检查。
- 支持原始点云、修正点云、叠加比较。
- 加入强度热力色、辉光、扫描线、极坐标刻度、方向标识。
- 加入转速、包率、最近距离、有效点、平均强度、完整圈数与链路健康面板。
- CSV同时导出原始角、修正角、修正量、距离和强度。

## 运行

```bash
pip install -r requirements.txt
python ld14_viewer_v0_2.py
```

USB串口固定为921600。WiFi UDP仍使用ESP32命令端口4210、PC数据端口4211。

## 首轮建议

1. 先使用USB链路。
2. 显示模式选`原始+修正`，观察紫色原始点与热力色修正点的差异。
3. 使用平墙、纸箱、圆柱体，在0.3m、0.5m、1m、2m分别测试。
4. 记录CRC错误、角跨度拒绝、最近距离和点云轮廓。
5. USB稳定后再切换WiFi UDP。

## 安全范围

本版仅用于传感器评估和二维环境显示，不输出M100运动命令，不包含自动减速或STOP逻辑。
